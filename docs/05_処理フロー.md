# 処理フロー（主要ユースケースのシーケンス図）

## UC1: `run` — スコアリング結果の表示（現状の主要フロー）

```mermaid
sequenceDiagram
    actor U as 利用者
    participant CLI as cli.cmd_run
    participant DS as MockDataSource(M1)
    participant M5 as build_features(M5)
    participant M6 as score_race(M6)
    participant M7 as m7_output(M7)

    U->>CLI: python -m keiba.cli run [--csv]
    CLI->>DS: fetch_race_card(race_id)
    DS-->>CLI: RaceCard
    loop 出走馬ごと
        CLI->>DS: fetch_jockey_stats(jockey)
        CLI->>DS: fetch_trainer_stats(trainer)
        CLI->>DS: fetch_past_performances(horse_name)
    end
    Note over CLI: paddock_scores は常に None（M4未接続、02_画面設計.md S5参照）
    CLI->>M5: build_features(card, jockey率, trainer率, None, 過去成績)
    M5-->>CLI: list[FeatureRow]
    CLI->>M6: score_race(features)
    M6-->>CLI: list[ScoreResult]
    CLI->>M7: print_report(results)
    M7-->>U: ランキング・買い目候補を標準出力
    opt --csv指定時
        CLI->>M7: export_csv(results, path)
        M7-->>U: CSVファイル出力
    end
    Note over DS,M7: db.pyへの保存は行われない（永続化ギャップ、UC5参照）
```

## UC2: `backtest-demo` — M8バックテスト実行

```mermaid
sequenceDiagram
    actor U as 利用者
    participant CLI as cli.cmd_backtest_demo
    participant DD as demo_data.generate_backtest_cases
    participant M6 as score_race(M6)
    participant M8 as run_backtest(M8)

    U->>CLI: python -m keiba.cli backtest-demo --races N
    CLI-->>U: 「合成データでの動作確認のみ」の警告メッセージ
    CLI->>DD: generate_backtest_cases(n_races)
    loop レースごと(N回)
        DD->>DD: 合成レース生成（乱数シード固定）
        DD->>M6: score_race(features)
        M6-->>DD: list[ScoreResult]
    end
    DD-->>CLI: list[BacktestCase]
    CLI->>M8: run_backtest(cases)
    M8-->>CLI: BacktestReport（単勝・複勝の的中率/回収率）
    CLI-->>U: format_backtest_report(report) を標準出力
```

## UC3: `tune-weights` — M9重み探索実行

```mermaid
sequenceDiagram
    actor U as 利用者
    participant CLI as cli.cmd_tune_weights
    participant DD as demo_data.generate_backtest_fixtures
    participant M9 as m9_weight_tuning
    participant M6 as score_race(M6)
    participant M8 as run_backtest(M8)

    U->>CLI: python -m keiba.cli tune-weights --trials N
    CLI-->>U: 「合成データはオッズ基準に偏る」の警告メッセージ
    CLI->>DD: generate_backtest_fixtures(n_races)
    DD-->>CLI: list[BacktestFixture]（スコア計算前の特徴量）
    CLI->>M9: build_tuning_result(fixtures, DEFAULT_WEIGHTS)
    M9->>M6: score_race(features, DEFAULT_WEIGHTS)
    M9->>M8: run_backtest(cases)
    M9-->>CLI: baseline: TuningResult
    CLI->>M9: random_search(fixtures, n_trials)
    loop 試行回数(n_trials回)
        M9->>M9: 単体(simplex)上でランダムな重みを生成
        M9->>M6: score_race(features, 重み候補)
        M9->>M8: run_backtest(cases)
        M9->>M9: TuningResultを記録
    end
    M9-->>CLI: 目的関数降順のlist[TuningResult]
    CLI-->>U: format_tuning_summary(baseline, results) を標準出力
```
