## 本書一式の位置づけ

- `要件定義書.md`（Phase 1スコープの機能要件・非機能要件・未決定事項）を前提知識とし、その内容を実装可能な設計に落とし込んだもの。
- 本ドキュメント作成時点（2026-08-07）では、**ドキュメント化のみ**を目的としており、記載されている設計の一部（新規テーブル、M4のCLI接続等）はまだ実装されていない。各ドキュメント内で「現状」と「設計（未実装）」を明確に区別して記載している。
- 実装が必要な項目は `要件定義書.md` の「12. 未決定事項・要確認事項」および各ドキュメント内の該当箇所にオープン課題として記載している。

## Mermaidダイアグラムのレンダリングについて

本ドキュメント一式ではMermaid記法（`flowchart`、`erDiagram`、`sequenceDiagram`）を使用している。

- **GitHub**（`github`リモート）: `.md`ファイル内のMermaidブロックを標準でレンダリングする。
- **Backlog**（`origin`リモート）: Backlogのファイル閲覧・Wiki機能はMermaidの標準サポートが無い、またはバージョンによって対応状況が異なる場合がある。Backlog上で図が正しく表示されない場合は、GitHub側（`github`リモート）を参照すること。
